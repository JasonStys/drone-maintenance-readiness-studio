# Security reporting

Do not post credentials, real fleet data, private exports or exploit material containing personal data in public issues. Use the private vulnerability reporting feature on this GitHub repository when available, or contact [Jason Stys on LinkedIn](https://www.linkedin.com/in/jason-stys-31b30b351/) to arrange a private report. Do not send secrets in an initial public message.

Report source revision, reproduction using disposable synthetic data, expected/observed behavior and potential impact. Test only your authorized local instance. No permission is granted to probe real drone hardware, third-party infrastructure or other users' data. The current main branch is the supported development line; no security response SLA or production assurance is promised. See the [threat model](docs/SECURITY.md).
